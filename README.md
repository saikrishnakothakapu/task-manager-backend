# Task Manager Backend API

## 🚀 Overview

A production-ready backend system built using Spring Boot to manage tasks with authentication and role-based access.

## 🛠️ Tech Stack

* Java
* Spring Boot
* Spring Security (JWT)
* Spring Data JPA (Hibernate)
* MySQL

## 📌 Features

* User Registration & Login (JWT Authentication)
* Create, Update, Delete Tasks
* Task Filtering (Status, Priority)
* Pagination & Sorting
* Global Exception Handling

## 📂 Project Structure

```
com.taskmanager
 ┣ entity
 ┣ dto
 ┣ repository
 ┣ service
 ┣ controller
 ┣ security
 ┣ exception
 ┗ utility
```

## ⚙️ Setup Instructions

1. Clone the repository
2. Configure database in `application.yml`
3. Run the application
